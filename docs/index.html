2. Structure de marché

3. Risque — style légendes

  • Couper les pertes vite (SL toujours placé).
  • Risque ≤ 1–2 % du capital démo par trade.
  • R:R ≥ 1.5 privilégié.
  • Après 3 pertes d’affilée : baisser temporairement le % de risque (esprit Turtle).

4. Carte signal enrichie

Chaque signal actif affiche niveaux Fib, R:R, confiance, session et divergence multi-sources — pour copier en conscience sur Exness DÉMO.

5. École des légendes

  • PTJ — discipline du plan : entrée/sortie définies avant le trade ; émotion hors du cockpit.
  • Seykota — « cut losses » : une petite perte maîtrisée bat l’espoir de rebond.
  • Turtles — règles fixes + taille de position ; après une série de pertes, réduire le risque, pas « se refaire ».
  • Fib — outil de repère (zones), pas une prédiction ; confluence > niveau isolé.

Éducation seulement — aucune promesse de résultat.

6. Indicateurs — RSI (14) + EMA (20/50)

Calculés sur l’historique local de prix (pas un feed broker). RSI extrême (<30 / >70) = prudence. Alignement momentum + RSI non extrême + prix vs EMA peut légèrement renforcer la confiance affichée.
